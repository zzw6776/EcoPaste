# 1.1.236

- 重构多通道同步控制面与数据面策略：所有剪贴板与分享记录的轻量元数据都会自动同步至云端和全部已配对局域网设备，局域网离线时分享的大文件在重新连入局域网后可自动补齐局域网状态并点亮图标；超限大文件继续按策略延后上传附件本体，并支持云端已有附件自动核查或手动点击上传。
- 修复局域网大文件与单张图片文件卡片在接收端和发送端（含 Android 卡片）的实时进度显示：接收进度按实际网络接收字节线性平滑推进，发送端按请求卡片精确绑定进度，即使多次分享同一份去重文件也不会错绑旧卡片或丢失进度条。
- 同步更新 Android 端打包资源中的托盘图标文件，与新版视觉样式保持一致。
- 本版本同步协议升级至 `v32`，需将各客户端与同步服务（`0.1.42` 及以上）配套升级；旧版本地数据库会在升级后自动迁移，保留既有历史记录。
