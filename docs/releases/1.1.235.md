# 1.1.235

- 为超限大文件与仅通过局域网同步的项目增加云端已有附件自动核查：当云端 Hub 已存有相同加密附件时，无需重复上传大文件即可直接确认云端完成；本版本同步协议升级至 `v31`，需与对应版本同步服务配套升级。
- 修复云端大文件上传期间传输卡片进度长期停在 0% 或发送完毕前提前跳到 100% 的问题，现在会按分片写入实时平滑推进，并在云端真正落盘确认后再标记完成。
- 修复云端数据连接卡死或半断开时上传直接中断且重试无退避等待的问题，增加连接健康探测、坏连接自动重建与失败指数退避重连。
- 在传输中心为同步中的文本记录与图片、文件补充“来自设备 / 云端”的来源展示，便于一眼识别当前同步来源。
- 统一隐藏云端待上传计数角标与排队提示，与局域网保持一致；优化卡片云端/局域网手动上传下载按钮颜色，未完成且需手动操作时统一以蓝色清晰标识，并修复未配对时仍显示可同步提示的问题。
- 更新桌面端与移动端应用及托盘图标视觉样式；重构云端与局域网同步状态弹窗，桌面端支持以独立浮窗形式查看云端设备、云端记录、配额用量及节点网络详情，并优化悬浮窗、抽屉、气泡与弹窗容器的视觉一致性。
