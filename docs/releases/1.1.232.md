# 1.1.232

- 修复多端同步下对条目进行收藏、置顶或备注修改时，因密文校验状态不同步导致远端快照正文丢失或本地流式上传凭据失效的问题。
- 修复局域网接收端未下载文件的 WiFi 图标误显绿色、发送端未下载大文件长期停留在“等待同步”以及主动拉取后对端状态未及时收敛的问题；未下载文件在局域网通道统一保持蓝色并可直接点击下载。
- 修复 Android 通过系统分享发送大文件且局域网在线时，云端图标卡死在“绿色 + 等待同步”且点击无效的问题，并在升级后自动清理旧版残留状态；现在该场景下云端默认保持灰色可点击，按需手动上传。
- 修复对已保存到外部目录的远端文件点击上传云端报错、收到收藏/备注更新后外部保存状态丢失，以及远端缺失单个附件时阻塞后续图片与文件自动拉取和文件夹再次分享异常的问题。
- 优化局域网与云端大文件传输速度：增大 QUIC 流控窗口与传输缓冲、解耦分片网络收发与加解密落盘，并改为按同步组密钥确定性派生文件标识，使跨设备重复文件与局域网下载后的文件可直接秒传复用。
- 修复同版本快照合并导致个别记录持续云端冲突循环，以及局域网内旧协议版本设备反复发送无效请求占满 CPU 与日志的问题。
