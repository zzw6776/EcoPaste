# 1.1.231

- 将多端同步引擎与云端同步协议全面重构为“按条目最新快照（Per-Item State）”模式，发送与拉取始终最新优先，并在控制连接之外独立复用数据连接传输附件，彻底解决历史积压或大文件传输阻塞最新复制的文本与图片同步的问题；由于同步协议与数据结构升级，客户端与云端同步服务需同步更新，已有本地剪贴板历史、配对设备与同步密钥将在升级后自动保留，无需重新配对。
- 修复开启“自动写入系统剪贴板”与 Windows 同步富文本/HTML 内容时，因系统剪贴板包装格式差异导致单次复制生成两条记录的问题。
- 优化局域网与云端同步状态反馈速度，消除接收端入站回执触发多余反向同步及呼出窗口后 WiFi/云端图标延迟变绿或短暂灰闪的问题。
- 统一剪贴板窗口可见性与休眠调度状态，刚隐藏时保持短期热同步，进入休眠后暂停后台查询并在重新打开窗口时即时补齐状态。
