# 1.1.164

- Android 新增系统“分享至 EcoPaste”入口，可接收其他应用分享的文本、链接、图片、视频、音频、文档及其他文件，支持一次分享多项内容；收录后按现有设置参与多端同步。
- 分享附件会保存到应用内，避免来源应用的临时读取权限失效后无法打开；无法解码的图片保留为原文件，并提示收录、跳过或失败的数量。
- 长文件名缩短时保留扩展名，APNG 动画按原文件收录，避免分享后无法识别文件类型或丢失动画。
- 删除分享附件的历史记录后会回收不再被引用的副本；其他记录仍在使用的附件会保留。备份恢复和更换数据目录后，分享附件仍可正常访问。
- 清理 Android 构建中的未使用代码告警。
