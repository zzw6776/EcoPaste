# 1.1.200

- 修复局域网连接只能由建立方向发起请求的问题，现有连接现在支持任一设备反向拉取文件。
- 云端自动上传上限不再阻止局域网文件传输；局域网是否自动接收文件只由接收设备的自动接收上限决定。
- 超过云端自动上传上限时仍同步文件元数据，并保留手动上传完整文件的入口。
- 云端或局域网设备仅收到文件记录时使用独立的信息色状态并保留补传入口，完整文件同步成功后才显示绿色。
- 仅交换文件记录时不再生成文件传输进度；局域网确认需要内容后才展示实际文件传输。
- 同步状态拆分为路由传输、设备内容副本和当前任务三类事实，Wi‑Fi 与云端同时到达时不再互相覆盖图标或操作。
- 局域网仅记录状态改为由接收设备主动下载，不再从发送端错误推送；LAN 重试也不会修改云端补传状态。
- 接收设备手动下载局域网文件时，发送端现在也会显示同一传输的进度、速度、完成状态并支持取消；下载完成后会记录实际使用的路径，外部保存不再冒充应用内缓存。
- 接收端的未下载文件不再因为记录已经到达而显示绿色；可直接选择局域网或云端保存，外部保存成功与应用内完整副本会分别显示。
- 云端暂未收到大文件内容时，下载失败会保留文件卡片和重试入口，发送端后续补传后仍可继续下载。
- 修复部分测试版本升级后因已执行同步迁移校验值不同而在启动阶段闪退的问题，缺失结构会在校验完整后安全补齐，现有历史和同步数据会原样保留。
- Android 下载文件到已有同名文件的目录时会自动添加序号，不再覆盖原文件或在完成阶段提示保存失败。
- 批量重连时离线设备不再覆盖其他在线设备的成功结果，并使用明确的不可达提示。
- 接收设备在传输前会区分“超过自动下载上限”和“本地已有相同内容”；后者直接复用现有副本，不重复传文件。
- 局域网卡片状态只统计该记录实际投递过的设备，离线的历史配对设备不再让已成功投递的记录长期显示为部分完成。
