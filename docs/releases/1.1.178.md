# 1.1.178

- 修复桌面端启动后可能只扫描局域网却不发布自身设备信息，导致 Android 的“附近同步空间”找不到桌面设备的问题。
- 附近设备刷新现在会完整收集本轮扫描结果，不再被旧缓存提前结束；设备持续在线时也会刷新存活时间，不会在广播内容未变化时从列表消失。
- 已配对设备的局域网地址解析与附近设备发现不再互相排斥，删除后重新批准设备时可以正常发起配对。
- 修复重新批准已删除设备后，云端旧状态可能让该设备立即退出同步空间并关闭同步的问题。
- 附近设备配对成功后会自动关闭配对界面并刷新同步状态。
- 修复局域网收到的记录被错误显示为正在由本机上传云端、实际却没有上传任务的问题。
- 安卓分享会在同步与局域网均可用时才选择附近设备；仅选定一种传输方式的记录现在可通过另一图标手动切换。
- 修复旧格式事件或缺失附件的单条任务阻塞整个云端发送队列的问题；升级后会保留本地记录并重新生成可发送的当前格式事件，手动重试也会重新准备内容。
