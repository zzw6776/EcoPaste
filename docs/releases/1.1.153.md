# 1.1.153

- 修复数据库并发写入锁争用导致的本地复制与列表刷新延迟，为 SQLite 增加忙等缓冲。
- 本地复制与同步任务改为原子持久化并由后台可靠处理，应用退出、加密失败或短暂文件异常不再静默丢失待同步内容。
- 修复快速复制后立即删除时可能出现的跨设备内容复现问题；同一条记录严格保持内容、删除和恢复顺序，同时允许不同记录轻度乱序以维持吞吐。
- 同步拉取按批次原子保存事件与游标，修复局域网游标无法推进导致的重复拉取。
- 无效远端事件会被隔离，数据库或文件系统等临时失败则按退避策略自动重试，不再把失败误记为已应用。
- 合并多端同步入站批量通知，避免密集同步时频繁触发界面重载与多余查询。
