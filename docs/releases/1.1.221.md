# 1.1.221

- 卡片时间旁新增采集设备，本机来源显示“本机”；来源应用保留图标，悬停或点按图标可查看完整应用名与设备名。
- 来源信息随加密元数据在局域网和云端传递；上传、下载及从历史复制时保留原来源，同内容重新采集时更新来源应用与设备。
- Android 系统分享尝试记录发送应用；无法识别的来源显示“未知应用”或“未知设备”，保留已有历史数据。
- 移除会误拦正常记录的来源设备格式校验，升级时自动恢复此前因此被阻断的发送和接收任务。
- 移除启动时闪动的蓝色方块和独立空白占位页；统一窗口与页面背景，减少主题切换闪烁。
- Android 启动时显示系统原生应用 Logo，页面外壳可绘制后进入应用，不增加固定停留时间；优先展示标题、搜索和分类栏，再加载历史内容。
- 减少启动时重复的文件历史扫描，首屏优先使用缓存图标；权限弹窗和传输记录详情按需加载。
- 新增启动分段耗时日志，便于定位原生窗口、WebView、数据库和首屏渲染的耗时。
- 修复 Hub 自动清理后，客户端仍可能把已删除的云端文件显示为完整同步的问题；在线设备收到清理通知后更新状态，离线设备重连后补齐。
- 云端状态核对按批次查询记录和文件索引，不下载文件；同一轮清理合并通知，未发生新清理时不重复核对。
- 修复按复制次数、创建时间等顺序浏览时，新复制或重复复制记录可能导致列表错序、滚动后重复或漏显示的问题。
- 此次同步协议升级，macOS、Windows、Android 客户端与 Hub 需一起更新；Hub 升级保留现有数据，并在首次连接时核对升级前已清理的记录。
- 修复导致桌面和 Android 发布构建中断的前端兼容问题。
