# 1.1.219

- 卡片顶部在时间旁显示采集设备，本机来源显示“本机”；来源应用保留图标，悬停或点按图标可查看完整应用名与设备名。
- 来源随现有加密元数据在局域网和云端传递，上传、下载及从历史复制时保留原来源，同内容重新采集时一起更新应用与设备信息。
- Android 系统分享尝试记录发送应用；旧记录或无法识别的来源显示“未知应用”或“未知设备”，保留已有历史数据。
- 客户端需更新以显示设备来源，Hub 无需更新。
- 移除会误拦正常记录的来源设备格式校验，升级时自动恢复此前因此被阻断的发送和接收任务。
- 移除启动时闪动的蓝色方块，等待本地设置时保持主题背景；文件路径规范化完成后记录标记，普通启动不再重复扫描全部文件历史。
- 统一 Android 原生窗口、WebView、启动等待与主页面的背景，移除独立空白占位页；启动时先沿用系统主题，读取真实设置后在绘制前应用，减少背景切换闪烁。
- Android 启动时显示系统原生应用 Logo，页面外壳可绘制后直接进入应用，不增加固定停留时间；随后继续加载中间的历史内容。
- 首屏文件列表优先使用缓存图标，缺失图标在可见文件行显示后补齐；复用已有的后台缩略图预热。
- Android 权限弹窗需要打开时才加载；传输列表的设备、分组与历史卡片详情改为打开弹窗时读取，减少冷启动首屏的额外查询。
- 启动时优先显示标题、搜索和分类栏，自定义分组从本地异步补齐；内容区域单独加载，记录查询与卡片代码加载并行，保持页面尺寸稳定，不增加固定等待。
- 启动日志分别记录外壳和卡片首次显示的耗时，便于观察界面响应与记录加载的实际变化。
- 新增启动分段耗时日志，覆盖 Android Activity 与 WebView 创建、网页加载、Rust 初始化、数据库、资源路径处理、设置请求排队与快照读取、首批记录返回及首次列表渲染，便于后续定位启动耗时。
