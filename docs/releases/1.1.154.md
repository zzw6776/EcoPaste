# 1.1.154

- 修复删除记录后重新复制并修改收藏、置顶或备注时，状态事件可能越过删除顺序并导致其他设备最终仍显示为已删除的问题。
- 配对码改为 5 分钟有效且只能使用一次的在线邀请，组密钥仅在生成设备明确批准后通过加密连接传输；附近配对会先确认空间切换，并在同一次握手中完成双方确认；旧版配对码不再接受，需要重新生成。
- 云端状态菜单新增设备列表，可查看已配对设备总数、在线状态、客户端版本和最近在线时间。
- 云端 Hub 改为有界加密同步缓冲：默认按 90 天、10 万条事件和每空间 10 GiB 配额保留，后台回收过期事件与不再引用的密文文件；容量不足时会先异步腾出空间再重试，设备列表同时显示当前云端用量和保留范围。
- 新设备首次同步会以连接时的固定云端快照为终点，完整恢复 Hub 当前仍保留的密文事件后，再按本机历史保留时长和最大条数清理；本机同时回收已超出保留范围的同步内容与密文附件，避免持续写入时首次同步无法结束或同步缓存绕过本机上限。
- Hub 配额回收现在会立即释放已淘汰事件引用的附件，并校验事件引用的附件仍然存在，避免大量近期附件占满空间后长时间无法继续上传。
- 上述云端设备与保留策略需要同步服务升级至 v0.1.17；现有同步空间和已配对设备无需重新创建，升级前已有的密文附件会先保守保留一个云端保留周期以避免误删。
