# 1.1.146

- 支持剪贴板卡片的收藏、置顶和备注跨端自动双向同步；各字段独立合并，离线修改、乱序到达或应用退出后也会可靠补发并收敛。
- 引入可持久化的删除与重新复制状态，删除会同步到其他配对设备；已删除的图片或文件不会再因旧同步任务被下载，之后主动重新复制仍可恢复。
- 云端记录只按实际剪贴板内容计数和分页，收藏、置顶、备注等状态同步不再造成空白页或数量偏差。
- 关闭敏感内容同步后，相关收藏、置顶和备注也不会发送；此前已同步内容的删除仍会正常传播。
- 备份合并会保留文件卡片的跨端身份，导入后继续正确关联后续状态变更。
- 同步组内设备需要全部升级到本版本；自建同步服务需要同步升级到 `0.1.15`，以支持新的内容与状态事件协议。
