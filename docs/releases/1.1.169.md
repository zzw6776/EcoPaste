# 1.1.169

- 修复 Android 文件管理器连续分享时 EcoPaste 退出、分享无响应的问题，分享入口统一接收文本、图片及各种文件。
- 手动分享按明确的收录与同步操作处理，不受自动采集类型、大小、敏感内容过滤、纯文本转换和自动文件上传阈值限制。
- 分享内容与同步任务一起保存，离线、同步关闭或尚未配对时也会进入等待队列；首次配对后仍按手动分享处理，应用重启、失败重试或相同内容再次收录后，任务也会保留。
- 等待生成同步内容的手动分享不会被自动历史清理提前删除，收录反馈会明确提示已加入同步队列。
- 云端同步按记录确认，已完成上传的文件可先完成同步，不再等待同轮其他文件；附件继续受控并行上传，单个附件失败不会取消其他附件。
- 修复局域网接收后误显示云端成功的问题，云端成功以实际服务端确认记录为依据；升级后会自动核对内容及收藏、置顶、备注等旧版状态，保留本地历史和附件。
- 同步记录区分等待、上传、待确认与失败状态，已确认成功的记录不会因其他任务失败而回退。
- 修复 Android VPN 等网络不支持 UDP 分段发送时云端同步卡住的问题，传输连接可自动降级继续发送；正常情况下保留分段发送加速。
- 附件上传在请求或传输长期没有进展时及时结束等待，并核验连接后恢复；正常持续上传的大文件不受总时长限制，单个任务失败不会直接断开仍健康的连接。
- 云端默认取消按时间和事件数量淘汰，仅保留每空间 10 GiB 容量限制；显式配置的时间、数量限制继续生效。
- 收藏、置顶记录及其附件豁免云端自动清理，取消保护后重新参与淘汰；离线设备的保护状态会保留至同步一致或移除该设备。保护内容仍占用空间，容量已被保护内容占满时，新上传会等待空间释放。
- 修复升级补齐旧历史时，删除后重新收录并收藏、置顶的内容可能漏报云端保护的问题，同时避免已删除的旧内容在并发同步时重新出现。
- 修复设备时钟存在偏差时，旧历史补齐后仍可能覆盖本机后续操作的问题；旧内容被删除状态拦截时，列表和 Android 悬浮面板会及时刷新。
- 修复仅通过云端连接的设备被移除后持续报错、未退出原空间的问题；被移除设备重新获批加入同一空间后，会重新上报收藏、置顶保护。
- 云端同步需要服务端升级到 0.1.22。升级前的密文历史先保守保留，连接新版客户端后自动补齐清理标识，再继续上传新内容；空间已满时，补齐不受上传失败退避拖慢，无需重建同步空间或重新配对。
- 更新同步传输组件，包含网络切换地址刷新、连接停滞及代理连接相关修复。
- 修复同时进行桌面与 Android 构建时，缓存清理导致 Android 构建依赖缺失的问题。
