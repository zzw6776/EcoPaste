# 1.1.239

- 修复远端删除带附件记录时可能因锁重入导致同步任务卡死的稳定性问题，并修复取消自动下载后卡片与列表未立即刷新的问题。
- 修复云端大文件持续上传时因管道写超时误判而中断的问题，改为在多路分片发送层按网络块超时检测断流，避免慢网误杀并恢复中文超时提示；同步修复重试上传时进度条虚增或跳变以及云端专用数据连接空闲切换竞态。
- 优化超长文本或备注超出单帧上限时的同步容错：在本地快照准备阶段提前拦截并保留既有已同步状态，防止单条超限记录阻塞后续全部设备的同步队列，卡片明确提示错误并支持编辑缩短后自动恢复或手动重试。
- 修复手动重试与局域网/云端多副本供源边界问题：已下载或未下载的远端文件卡片可正常重试失败的收藏/置顶/备注同步，局域网多个相同文件副本中单个原文件缺失时自动回退到其余可用副本，目录异步统计大小并发复制时不再误取消新记录同步。
- 修复 Android 分享大文件导入期间的临时清理保护与本地保留淘汰策略：避免非云端上传的大文件长期占用本地历史配额，并保护本地刚淘汰但尚未完成同步的记录在 24 小时内继续发出。
